# BentoMenu 人工测试清单

版本：1.0.0  
用途：发布前人工验收、升级回归、交付验收  
建议环境：独立测试服，保留一份可恢复的 `plugins/BentoMenu/` 备份

准备：

1. 至少两个账号：管理员（OP）与普通玩家（无管理权限）。
2. 普通玩家准备一定经济余额（用经济插件命令，如 `/eco give <玩家> 1000`）。
3. 备份 `plugins/BentoMenu/`。
4. 记录控制台是否有报错；每个失败项都附控制台日志。
